# Update Application Link Host

## Goal

Ensure links generated by Strillone point to `https://app.dnsimple.com`, while
retaining `DNSIMPLE_URL` as an override for other deployments.

## Implementation

1. Update the `DNSIMPLE_URL` default in `internal/config/config.go` from
   `https://dnsimple.com` to `https://app.dnsimple.com`.
2. Leave the `DNSIMPLE_URL` environment variable and the `FmtURL` helper in
   place so deployments can explicitly select another application host.
3. Update expected generated-link hosts in:
   - `internal/service/message_test.go`
   - `internal/http/server_test.go`
4. Update the `DNSIMPLE_URL` default shown in `README.md`.
5. Add or update a focused test confirming both the new default and an explicit
   `DNSIMPLE_URL` override produce the intended link host.

## Verification

1. Run `go test ./...`.
2. Search application-link output and test fixtures to confirm generated links
   use `https://app.dnsimple.com` by default.
3. Confirm remaining bare `https://dnsimple.com` references, if any, are
   public-site or documentation links rather than dashboard/application links.
